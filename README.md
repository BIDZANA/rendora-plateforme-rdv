# rendora-plateforme-rdv
Rendora est une plateforme universelle de prise de rendez-vous, conçue pour s’adapter à de multiples secteurs : santé, beauté, consulting, services à domicile, éducation, etc. Développée en Java 17 avec Spring Boot, Rendora propose une architecture moderne, sécurisée (JWT), RESTful et facilement extensible.
